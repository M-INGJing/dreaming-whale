## 上游 4.1.5 ~ 4.2.0 更新内容（按主题）

1. **连续消息收集**（4.1.6）：`chat.messageSettleMs`(1500) + `chat.groupMaxBatchWaitMs`(5000)，私信/群聊都先攒后回。
2. **搜索升级**（4.1.5）：本地 Bing/360 强制开启 + 可选 API 搜索（DeepSeek `/v1/tools/search` + 知乎 `zhihu_search`）+ 配额。
3. **人设模块化 + 预设管理 + 打包分享**（4.2.0/4.1.5）：人设拆模块拼装；预设另存/改名/删除/自动回写；ZIP 打包分享、本地安装、插件市场联动。
4. **config 目录化**（4.1.6.1）：`config.json` → `data/config.json`，迁移+备份+校验。
5. **朋友圈**：`bridge/moments.py` 调 `wechatauto` 读 `sns.db`（只读、赞/评论 UIA、发布高风险）。
6. **插件市场**：appEpoch 双代兼容 + 签名 + 溯源 + 隔离执行。
7. **官网 website/**：静态站（下载中心、Star 数、赞助入口）。
8. 一批 bridge/chat/pipeline 修复（发送失败跳过、引用接收、API Key 漏空格、讨论模式字数上限、过滤泄漏时间标记等）。

## 本项目采纳决策（2026-11-16）

| 上游改动 | 决策 | 说明 |
|---|---|---|
| 连续消息收集 | ✅ **部分采纳** | 只把「群聊也共用固定 1500ms 窗口」并进本地（见 `docs/私聊消息防抖方案.md` §10）；不引入 settle/群聊批次上限（固定窗口更简单，够用） |
| 搜索升级（API/知乎） | ⏸ 暂不 | 本项目已走 `deepseek_web_search` 托管搜索路线（上游是「本地+API」），方向不同，不混用 |
| 人设模块化+打包分享 | ⏸ 暂不 | 大重构，与本地人设锚定清理改动冲突 |
| config 目录化 | ⏸ 暂不 | 工程卫生，可选 |
| 朋友圈 | ⏸ 暂不 | 依赖 `wechatauto`(PyPI)+Python3.12+管理员权限，写操作有账号风险 |
| 插件市场 | ❌ 不引入 | 生态层，fork 无第三方插件需求 |
| 官网 website | ❌ 不引入 | 分发/宣传层，与核心无关 |
