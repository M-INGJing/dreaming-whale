# 小红书技能

鲸鲸能帮你**搜攻略、读笔记、发图文笔记**（都走你本机跑着的一个小红书服务）。默认关闭，需要先开开关 + 起服务。

## 依赖：一个本机小红书服务

小红书没有公开 API，操作靠浏览器自动化。鲸鲸自己不打包浏览器，只做 HTTP 客户端，去调一个**本机服务**（`xiaohongshu-mcp`）。可以直接复用 [dsh-xhs-whale](https://github.com/Zhouzhounb520/dsh-xhs-whale) 里的修改版服务（Go 程序，跑起来监听 `http://127.0.0.1:18060`，支持扫码登录、搜索、读详情、发图文笔记）。

**启动顺序**：先起小红书服务（并扫码登录）→ 再开鲸鲸的开关。

## 配置

`config.json` / 启动器「实验开关」：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `features.xhs` | `false` | 总开关（调试台「功能开关」也能切） |
| `xhs.url` | `http://127.0.0.1:18060` | 小红书服务地址 |
| `xhs.token` | 空 | 服务令牌（服务端开了鉴权才填） |
| `xhs.timeoutMs` | `120000` | 单次请求超时 |
| `xhs.requireConfirm` | `true` | 发布前回显草稿、等对方「发」确认 |
| `xhs.maxPublishPerDay` | `3` | 每日发布上限（风控） |

## 用法

| 你想做的 | 怎么说 | 鲸鲸会 |
| --- | --- | --- |
| 搜攻略 | 「搜小红书 XX」「小红书搜一下 XX」 | 调服务搜索，回前 5 条（标题/作者/赞）+ 链接 |
| 读某条 | 搜完说「看第 N 条」 | 拉正文 + 评论数，回摘要 + 链接 |
| 发笔记 | 「发小红书：标题 X，内容 Y #标签 图:路径」 | 回显草稿，等你「发」确认才真正发布 |

发布走**草稿 → 确认 → 发送**（`requireConfirm=true` 时）：她会先把标题/正文/标签回显，你回「发」才发，回「不发」取消。

> 小红书图文笔记**至少要一张图**。图可以写 `图:本地路径` 或 `图:https://…`（一条可写多个）。没配图她会提醒「先发一张图」。

## 异常反馈（不会瞎说、不会自动重发）

- 服务没起 / 地址没配 → 明确提示检查服务。
- 没登录 / 验证码 / 风控 → 暂停，交你在服务端人工处理。
- 发布结果拿不到确认 → 明确「需人工核对，不自动重发」。

## 实现位置

- `src/adapters/xhs/client.js` — HTTP 客户端（`search` / `detail` / `publish` / `loginStatus`），错误分级、结果归一化，transport 可注入。
- `src/services/xhs.js` — 意图解析 + 状态机（上次搜索结果 / 待确认草稿）+ 草稿确认 + 反馈。
- `src/pipeline/chat.js` — `tryXhs` 命令式触发（排在提醒/农历/抽签/待办之后、正常聊天之前）。
- `src/services/capabilities.js` — 「上小红书」进能力清单提示词。

安全口径与参考项目（dsh-xhs-whale / dafeiyu-bot）一致：读操作低风险、写操作（发布）需确认 + 每日额度 + 结果核验，验证码/风控一律暂停交人工。
